💸 Pocket Money Tracker
Hey there! 👋 This is a simple, clean, and lightweight web application I built to keep track of my daily pocket money, expenses, and savings without any complicated bloat.

https://github.com/user-attachments/assets/d5f40dc7-4504-4995-bf53-66199b4153ec













✨ What does it do?
Real-time Balance: Instantly calculates your total balance, total income, and total expenses as you add new items.

Smart Categories: Organize your money with categories like Food, Transport, Entertainment, Shopping, Salary, and General Earnings.

Smart Signs: Automatically sets positive or negative values based on the category you pick—no need to manually type minus signs for your expenses!

Smart Budget Advisor: Gives you friendly tips and warnings based on your spending habits (like when you're crossing 80% of your earnings).

LocalStorage Persistence: Your data stays saved right in your browser, so nothing gets lost when you refresh or close the tab.

Quick Deletions: Easily remove any transaction from your history whenever you need to.

🛠️ Tech Stack
HTML5 for a clean, semantic layout

CSS3 for modern styling and responsive flexbox alignment

Vanilla JavaScript (ES6) for core functionality, state management, and storage

💡 How this was made
I built this project from scratch to practice working with DOM manipulation, browser local storage, and responsive CSS layouts. The main challenge was getting the form inputs and cards to look neat across different screen sizes and making sure the math for income/expenses updated smoothly.
